# ระบบเช็คชื่ออัตโนมัติด้วยใบหน้า (Face Attendance Kiosk)

ระบบเช็คชื่อด้วยใบหน้าแบบเดินผ่าน (Walk-through Face Recognition Attendance) ทำงานผ่านเว็บเบราว์เซอร์ รองรับการใช้งานทั้งบนคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ

## 🌟 ฟีเจอร์เด่น (Features)
- 🚶 **เดินผ่านเช็คชื่ออัตโนมัติ (Walk-through Auto Attendance)**: กล้องตรวจจับใบหน้าต่อเนื่อง ไม่ต้องกดปุ่ม
- 🔊 **ระบบเสียงแจ้งเตือน**: มีเสียงสัญญาณ Chime และเสียงสังเคราะห์ภาษาไทย (Web Speech API) ทักทายชื่อผู้เช็คชื่อ
- ⏳ **ระบบป้องกันบันทึกซ้ำ (Cooldown)**: ตั้งเวลาหน่วงเพื่อป้องกันการเช็คชื่อซ้ำของคนเดิม (1 นาที / 5 นาที / 30 นาที / 12 ชั่วโมง)
- 💾 **เก็บบันทึกข้อมูลในเครื่อง (Local Storage)**: บันทึกประวัติพร้อมวันเวลาและความมั่นใจ ข้อมูลไม่สูญหายเมื่อรีเฟรช
- 📥 **ส่งออกข้อมูลเป็น CSV**: ดาวน์โหลดข้อมูลเพื่อเปิดใน Microsoft Excel ได้ทันที (รองรับภาษาไทยด้วย UTF-8 BOM)
- 📱 **รองรับหน้าจอมือถือ (Responsive UI)**: ออกแบบมาให้แสดงผลสวยงามบนสมาร์ทโฟน

## 🤖 โมเดล Machine Learning
- พัฒนาด้วย Google Teachable Machine Image Model
- ประมวลผลผ่าน `@teachablemachine/image` และ TensorFlow.js

## 🚀 วิธีเปิดใช้งาน GitHub Pages
1. ไปที่แท็บ **Settings** ใน GitHub Repository ของคุณ
2. เลือกเมนู **Pages** ทางด้านซ้าย
3. ในส่วน **Build and deployment > Source** ให้เลือก **Deploy from a branch**
4. เลือก Branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอ 1-2 นาที คุณจะได้ URL แบบ HTTPS เช่น `https://<username>.github.io/<repo-name>/` เพื่อเปิดใช้งานบนมือถือได้ทันที
